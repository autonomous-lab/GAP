Execution mode

Always-on requires operator approval. In serverless mode, silent SSH, WebSocket and TCP connections can be closed when the VM hibernates. Outbound traffic does not keep it awake.

Spending budget

Reaching a budget suspends execution. An in-flight interval can cross the threshold; retained storage remains billable. Exhausting the credit balance starts a 72-hour storage retention period. Recharge before the displayed deadline to cancel deletion.
