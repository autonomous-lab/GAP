Docker applications / Experimental

Your Compose stack.
One project URL.

Run a full application in its own managed microVM. Deploy Docker builds, keep persistent volumes and publish through GAP's existing domain.

01

Create the runtime.

GAP creates the project's microVM. Start, stop, resize and destroy it through the API.

02

Deploy your stack.

Send your Compose files and build context. Poll the deployment job, then inspect status and logs.

03

Publish on the existing domain.

Enable the app's guest port at /apps/{project_id}/. No extra DNS record or TLS certificate. Configure your app's base path for its public URL.
