01 / Serverless microVMs

Real Linux.
Zero idle compute.

Your runtime, billed by usage. Run native binaries, scripts or optional Docker containers with SSH, persistent disks and public ports. In serverless mode, GAP hibernates your microVM after 15 idle minutes and resumes it automatically when a request arrives. Compute billing pauses while hibernated; stored data and network usage remain billable.

01

Run. Pay for usage.

Choose the CPU and RAM your app needs. Pay for active compute at published rates, with a prepaid balance and visible consumption.

02

Idle. Scale to zero.

After 15 minutes without inbound activity, GAP hibernates the runtime. Memory state and persistent files are retained for resume. Compute usage stops; storage continues to be charged.

03

Request. Resume automatically.

Incoming traffic triggers a resume, so your application can serve requests again. Resume takes time: use always-on mode for workloads that need continuous availability, subject to operator approval.
