Bounded by design.

Outbound access is limited to approved public package registries. Arbitrary internet access, private networks, scanning and SSH forwarding are blocked. Package traffic is rate- and volume-limited. If the region is full, try again later; a failed capacity attempt does not create a VM.

Good to know.

Do I need to sign up?

No. An account and verified email are required only if you choose to claim the VM.

Does disconnecting stop it?

No. It remains available for the rest of its one-hour build window.

What happens if I do not claim it?

The VM stops after one hour. Its disk is deleted when the 24-hour claim window expires.

Can others see my preview?

Not during the anonymous trial: both the SSH source IP and Basic Auth credentials are required.
